# Antonio Pablo — Story Maker

Landing page estática pronta para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.

O efeito 360° é uma animação visual 2.5D usando a foto original, preservando a fotografia. Um modelo 3D real exigiria múltiplos ângulos/fotogrametria.
